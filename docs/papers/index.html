Framework Papers

Longer standalone research artifacts, one level up from a diligence memo. Each paper states a bull or bear thesis fairly, builds a metric framework with triggers written down in advance, then tests every leg of the thesis against live on-chain data instead of the narrative. No exit levels, no return projections, no position sizes: the deliverable is a verdict plus a trigger list any reader can check without asking the author whether the call has changed.

The picks so far:

  • Hold It, Get Paid In Stocks: Stress-Testing the INDEX Bull Thesis Against Its Own Chain: five bull legs tested against contract and flow evidence. Four hold on mechanism and fail on scale; the fifth, orchestrator alignment, is an unverified narrative. Holder inflow down about 86 percent in nine days; the standing desk read (exit, watch-only below a $10M cap) stands.

Format follows an adapted Midwest Blockchain Conference written-report structure: title page, executive summary, project overview, stated bull thesis, framework and metric table, leg-by-leg verdict, risks, conclusion, live appendix and references. Deviations from the template are disclosed inside each paper.

Every desk on this site is paper only. No real trading profits are claimed anywhere. All data is self-collected from my own logs and public keyless sources. Methodology over outcomes.
