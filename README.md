# czr research

Self-collected market research, graded in public. Paper desks only; no real trading profits are claimed anywhere.

**Site:** https://cesalas13.github.io/czr-research/
**Live dashboards:** https://dune.com/czr

- `casestudies/` — deal-flow radar (sourcing engine), calibration report, AI investment committee
- `memos/` — four investment-committee-format diligence memos
- `map/` — launchpad infrastructure market map
- `data/` — the calibration script plus the scrubbed CSVs it reads; `python3 data/calibration.py` reproduces every number in the calibration report
- `docs/` — the site (GitHub Pages)

All datasets are scrubbed: caller handles and room names are pseudonymized, no wallet or personal financial data. Methodology over outcomes.
